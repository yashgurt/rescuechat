# Fork attribution and portfolio status

This public repository is a fork of BitChat. The upstream [README](README.md), license, architecture, and setup documentation are preserved unchanged. Existing messaging features, screenshots, performance claims and implementation are attributable to the upstream project unless separately demonstrated by a specific contribution.

A check of the repository's commit history did not return attributable commits for `yashgurt`. No original implementation, independent benchmark, or personal authorship of upstream features is claimed here. The separate RescueMesh safety evaluation is an independent educational project and should be described separately.

See [upstream documentation](README.md) for installation and demos. This fork is not currently a flagship portfolio project.
